Full-featured code editor with syntax highlighting, search and replace, file navigation, and multi-tab workflows.

Interactive terminal session connected to bash, npm, python, git, and custom build pipelines with hardware key toolbar.

Localhost Preview

Preview web applications in real time over loopback localhost without exposing ports or routing data to third parties.
