Pocket IDE

Privacy Policy

Effective date: November 4, 2026

Overview

Pocket IDE is a local-first Android development environment. All coding workspaces, Linux runtimes, terminal sessions, and project files reside locally on your device storage. This policy outlines what information the application handles, where it is stored, and when network communication occurs.

Information Handled Locally

Pocket IDE manages the following data locally within Android protected application sandbox:

  • Project source code, scripts, assets, and git repositories.
  • Third-party AI provider API keys, encrypted at rest using the hardware-backed Android Keystore.
  • Terminal command histories, log streams, and compilation artifacts.
  • Local web preview cache on loopback localhost interfaces.

Pocket IDE does not bundle advertising SDKs, tracking frameworks, or third-party behavioral analytics.

External Network Activity

Network activity is strictly limited to user-directed operations:

  • Runtime Components: When installing development stacks (Node.js, Python, Git, PRoot), packages are downloaded over HTTPS from official distribution mirrors.
  • User-Configured AI Services: When you invoke code assistance using your own API key, requests containing the relevant context are transmitted directly to the configured provider API (e.g., Anthropic, Google, OpenAI, DeepSeek). That communication is governed by the respective provider privacy policy.
  • Application Updates: Optional release checks contact the official GitHub Releases endpoint.

Data Retention and Control

You have complete control over all data. Deleting a project removes its workspace files from your device. Uninstalling Pocket IDE removes all private data and Keystore credentials according to standard Android platform behavior.
